# Results

Written by the scoring scripts from the nine runs (scored 19 October 2026); not edited by hand.

- `scores.csv`: every metric for every event and run (`scripts/scoring/score_all.py`)
- `SCORECARD.md`: headline table
- `HYPOTHESES.md`: pass/fail for the pre-registered criteria in `docs/metrics.md`
- `figures/story/`: the figures of the write-up (`scripts/scoring/story_figures.py`); the
  order and captions are in `docs/story.md`
- `figures/`: event-total maps and FSS curves (`scripts/scoring/plot_event.py`)
